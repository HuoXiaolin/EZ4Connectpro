# 高级使用方式

## 本机代理

每条配置都有独立的 SOCKS5 和 HTTP 端口，默认监听 `127.0.0.1`。可以在「编辑配置 → 高级」修改端口。端口需空闲，同一配置的两个端口也要不同。配置同时运行时，使用对应配置的端口访问相应的 VPN。

Windows 默认使用网关下发的内网路由。仅使用本机代理时，可关闭「编辑配置 → 高级 → TUN 模式」。系统代理正由其他软件或 PAC 管理时，本机端口仍可供支持独立代理设置的程序使用。 [浏览器访问内网页面](VPN_WORKSPACE.md#浏览器访问内网页面)

## TUN

自动内网路由使用内置 TUN 网卡和网关下发的路由。现有配置的 DNS 劫持和 Fake IP 选项继续有效。若 aTrust 网关发布了需要域名分流的资源，可在高级设置按网关要求开启这两项。

如需手动控制路由，开启 TUN 并关闭自动内网路由，再勾选对应的高级选项。使用虚拟网卡需要管理员权限。网卡已被占用时，应用会显示具体冲突。活动日志会保留重启前的错误记录。
